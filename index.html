📖 REST API Hujjatlari & Integratsiya Qo'llanmasi

Ushbu AI-Moderator tizimini veb-saytingizga, mobil ilovangizga yoki Telegram botingizga osongina ulashingiz mumkin.

1. Xabarni moderatsiya qilish (POST /api/moderate)

curl -X POST http://127.0.0.1:8080/api/moderate \ -H "Content-Type: application/json" \ -d '{ "text": "Telegram kanalimizga o'\''ting: https://t.me/kanal", "user_id": "tg_user_12345", "author_name": "Alisher" }'

2. Telegram Bot bilan integratsiya (Python aiogram misoli)

import urllib.request import json from aiogram import Bot, Dispatcher, types API_URL = "http://127.0.0.1:8080/api/moderate" async def check_message(text, user_id, author_name): payload = json.dumps({"text": text, "user_id": str(user_id), "author_name": author_name}).encode("utf-8") req = urllib.request.Request(API_URL, data=payload, headers={"Content-Type": "application/json"}) with urllib.request.urlopen(req) as response: return json.loads(response.read().decode("utf-8")) # Xabarlarni avtomatik ushlash: @dp.message() async def moderate_chat(message: types.Message): result = await check_message(message.text, message.from_user.id, message.from_user.full_name) if result["status"] == "BLOCKED": await message.delete() await message.answer(f"⚠️ {message.from_user.mention_html()}, xabaringiz qoidalarga zid bo'lgani uchun o'chirildi!\nSabab: {result['explanation_uz']}")
